# 08. A/B 테스트 설계: 신규 유저 첫 화면 인기 상품 노출

## 배경
07에서 첫날 상품을 본 신규 유저의 30일 리텐션(17.7%)이 보지 않은 유저(8.3%)의 2.1배였다. 하지만 이는 상관관계로, 구매 의향이 높은 유저가 상품도 보고 재방문도 했을 가능성(자기 선택 편향)이 있다. 상품 조회를 **유도했을 때** 실제로 개선되는지 무작위 실험으로 검증한다.

## 가설
> 신규 유저의 첫 화면에 인기 상품을 바로 노출하면, 첫날 상품 조회율이 오르고 30일 리텐션이 개선된다.

## 설계

| 항목 | 내용 | 근거 |
| --- | --- | --- |
| 대상 | 신규 유저 (첫 방문) | 개선 대상이 첫 화면이며, 기존 유저는 사이트에 익숙해 효과를 희석시킨다 |
| 무작위 배정 단위 | 사람 (`user_pseudo_id`) | 같은 유저가 두 화면을 번갈아 보면 효과를 구분할 수 없고, 지표가 유저 단위다 |
| A (대조군) | 기존 첫 화면 | |
| B (실험군) | 첫 화면 상단에 인기 상품 노출 | |
| 배정 비율 | 50 : 50 | |

## 지표

| 종류 | 지표 | 현재 값 | 역할 |
| --- | --- | --- | --- |
| 주 지표 | 첫날 상품 조회율 | 21.4% | 성공 판단 기준. 첫 화면 변화에 가장 직접 반응하고 첫날 측정 가능 |
| 보조 지표 | 30일 리텐션 | 10.6% | 최종 목표. 30일 관찰이 필요해 판단 기준으로는 느림 |
| 가드레일 | 첫날 구매 전환율 | 0.96% | 호기심 클릭만 늘고 구매가 줄면 실패 |
| 가드레일 | 첫 화면 바로 이탈률 | - | 화면이 복잡해져 이탈이 늘면 실패 |

## 표본 크기와 기간

- 유의수준 5%(양측), 검정력 80%
- 최소 검출 효과(MDE): 첫날 상품 조회율 +2%p (21.4% → 23.4%, 상대 +9.3%)

| 검출하려는 차이 | 그룹당 필요 인원 |
| --- | --- |
| 상품 조회율 +2%p | 약 6,800명 |
| 상품 조회율 +1%p | 약 26,800명 |
| 30일 리텐션 +1%p | 약 15,500명 |

- 신규 유저 유입은 하루 약 2,800명(2020-11 ~ 2021-01 평균)이라 13,600명은 약 5일에 모인다.
- 요일 효과를 포함하기 위해 **최소 7일**, 가능하면 14일 운영한다.
- 사전에 정한 기간 전에 결과를 보고 중단하지 않는다(peeking 방지).
- 30일 리텐션은 배정 종료 후 마지막 유저까지 30일을 추가 관찰한다.

## 판단 규칙 (사전 정의)

| 주 지표 | 가드레일 | 결론 |
| --- | --- | --- |
| 유의하게 상승 | 유의한 악화 없음 | 성공 → 전체 적용 |
| 유의하게 상승 | 유의하게 악화 | 실패 → 원인 분석 후 수정·재실험 |
| 유의한 변화 없음 | - | 효과 없음 → 다른 개선안 검토 |

## 분석 계획 (08-2)
1. 표본 비율 점검(SRM): 실제 배정이 50:50에서 크게 벗어나지 않았는지 확인
2. 주 지표: 두 비율 z-검정, 차이의 95% 신뢰구간, 상대 상승률
3. 가드레일 지표: 동일 검정으로 악화 여부 확인
4. 시각화: 그룹별 전환율과 신뢰구간 막대 그래프
5. 결론과 다음 행동
